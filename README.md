### 🟣 Level 3 – Task 3: Temperature Converter Website

**Project Name:** Temperature Converter

**Description:**

An interactive temperature conversion web application that allows users to convert temperature values between Celsius, Fahrenheit, and Kelvin.

**Key Features:**
- Celsius to Fahrenheit conversion
- Fahrenheit to Celsius conversion
- Celsius to Kelvin conversion
- Fahrenheit to Kelvin conversion
- Real-time conversion functionality
- Input validation and error handling
- Interactive and user-friendly interface

**Technologies Used:** HTML5, CSS3, JavaScript
