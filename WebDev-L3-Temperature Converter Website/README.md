\# Temperature Converter Website



\## 1. Project Overview



The Temperature Converter is a simple, user-friendly, and responsive web application developed as part of the Oasis Infobyte Web Development Internship.



The main purpose of this project is to provide an easy way to convert temperature values between three commonly used temperature units: Celsius, Fahrenheit, and Kelvin.



The website features a clean interface with a temperature input field, unit selection dropdown, and a Convert button. Its simple design allows users to enter a temperature value and perform conversions conveniently.

\## 4. Website Features



1\. \*\*Temperature Input:\*\* Allows users to enter a numerical temperature value.

2\. \*\*Unit Selection:\*\* Provides a dropdown menu for selecting the temperature unit.

3\. \*\*Celsius Conversion:\*\* Supports temperature conversion involving Celsius.

4\. \*\*Fahrenheit Conversion:\*\* Supports temperature conversion involving Fahrenheit.

5\. \*\*Kelvin Conversion:\*\* Supports temperature conversion involving Kelvin.

6\. \*\*Convert Button:\*\* Allows users to initiate the conversion process.

7\. \*\*Simple Interface:\*\* Provides a clean and organized layout.

8\. \*\*Attractive Design:\*\* Uses a light-blue background, white conversion card, and blue action button.



\## 5. Temperature Conversion Formulas



The application uses standard temperature conversion formulas:



\*\*Celsius to Fahrenheit:\*\*



°F = (°C × 9/5) + 32



\*\*Fahrenheit to Celsius:\*\*



°C = (°F − 32) × 5/9



\*\*Celsius to Kelvin:\*\*



K = °C + 273.15



\*\*Kelvin to Celsius:\*\*



°C = K − 273.15
